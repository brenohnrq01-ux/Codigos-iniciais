## 📚 Sobre o repositório

Este projeto reúne exercícios, pequenos programas e experimentos desenvolvidos durante meu aprendizado de lógica e programação.

A proposta é mostrar a evolução dos mesmos conceitos em diferentes linguagens, passando por algoritmos básicos, estruturas de repetição, condicionais, entrada e saída de dados e pequenos projetos completos.

## 🗂️ Organização

| Diretório | Conteúdo |
|---|---|
| `Cod C` | Exercícios e programas introdutórios em C |
| `Cod Java` | Exercícios equivalentes desenvolvidos em Java |
| `Cod Python` | Implementações e exercícios em Python |
| `Cod Portugol` | Algoritmos e fundamentos em pseudocódigo |
| `Cod Basic/Bigode Game` | Jogo 2D desenvolvido com AppGameKit |

## 🧠 Conceitos praticados

- Variáveis e tipos de dados
- Operadores e expressões
- Estruturas condicionais
- Laços `for`, `while` e `do while`
- Entrada e saída de dados
- Lógica de autenticação e validação
- Cálculos e conversões
- Organização de código
- Introdução à programação de jogos

## 🎮 Bigode Game

Além dos exercícios tradicionais, o repositório contém o projeto **Bigode Game**, um jogo 2D com recursos como:

- movimentação do personagem;
- pulo e gravidade;
- moedas e itens;
- inimigos;
- sistema de vidas;
- efeitos sonoros e música;
- sprites e animações.

## 🚀 Propósito

Mais do que concentrar exercícios, este repositório funciona como um histórico da minha evolução: do Portugol e primeiros programas até projetos com múltiplos arquivos e recursos multimídia.
